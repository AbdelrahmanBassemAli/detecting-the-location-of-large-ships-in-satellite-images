# Detecting the Location of Large Ships in Satellite Images

A convolutional neural network (CNN) that detects and locates ships in
satellite imagery, built to support port-activity monitoring and
supply-chain analysis.

## Overview
- **Role:** Model design & training
- **Status:** Completed
- **Tech:** Python, Jupyter Notebook, CNN (deep learning)

## What it does
The model takes satellite imagery as input and identifies the location of
large ships within it. Automating this detection can support:
- Monitoring port activity levels
- Supply-chain and shipping-traffic analysis

## Skills applied
Machine learning, computer vision (CNN), Python, data analysis.
